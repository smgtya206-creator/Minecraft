# Kublar Olami

Brauzerda ishlaydigan 3D blok-qurilish o'yini. Bloklarni buzing, qo'ying va o'z dunyoingizni quring.

**O'ynash:** https://smgtya206-creator.github.io/minecraft/

## Telefonga o'rnatish

1. Yuqoridagi havolani telefonda Chrome (Android) yoki Safari (iPhone) orqali oching.
2. Android: menyu (⋮) → "Ilovani o'rnatish" yoki "Bosh ekranga qo'shish".
   iPhone: "Ulashish" tugmasi → "Bosh ekranga qo'shish".
3. O'yin bosh ekranda ilova sifatida paydo bo'ladi va bir marta ochilgandan keyin internetsiz ham ishlaydi.

## Dunyolar

O'rmon, Orollar, Cho'l, Qorli tog'lar va Tekislik. Har biri alohida saqlanadi.

## Boshqaruv

- Telefon: chap doira bilan yurish, ekranni surib qarash, Buz / Qo'y / Sakra tugmalari.
- Kompyuter: W A S D, sichqoncha, chap tugma buzadi, o'ng tugma qo'yadi, 1-9 va 0 blok tanlaydi.
